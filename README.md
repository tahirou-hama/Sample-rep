# Sample Repository

A repository used to practice Git and GitHub fundamentals
and learn version control workflows.

- Understand repository creation and management.
- Practice writing Markdown documentation.
- Learn how to commit changes with meaningful messages.
- Become familiar with GitHub's repository interface.
- Develop good version control habits.

## Technologies

- Git
- GitHub
- Markdown

This repository documents my early learning and practice
